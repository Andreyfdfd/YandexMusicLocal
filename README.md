# YandexMusicLocal

Локальный музыкальный плеер для Windows с тёмным интерфейсом и жёлтым акцентом, вдохновлённым современными музыкальными приложениями. Проект не связан с Яндексом и не использует его закрытые ресурсы.

> **Состояние:** исходные варианты импортированы. Каноническая точка входа — `main.py`; сейчас проводим инкрементальную индексацию и проверяем приложение на Windows. Прежние варианты интерфейса сохранены как исторические реализации для сравнения.

## Основные цели

- Быстрый повторный запуск без повторного чтения тегов неизменившихся файлов.
- Инкрементальная индексация по абсолютному пути, размеру и времени изменения файла.
- Фоновое сканирование и загрузка обложек только когда это необходимо.
- SQLite-индекс и локальный кэш в профиле пользователя Windows.
- Поддержка MP3, M4A, FLAC, WAV, Ogg/Vorbis, Opus, WMA, AAC, APE, AIFF и ALAC при условии поддержки конкретного файла установленной версией VLC и Mutagen.
- Интерфейс с библиотекой альбомов, поиском, очередью и нижней панелью проигрывателя.

## Среда разработки

- Windows 10/11
- PowerShell 7
- Python 3.12+; проект также рассчитан на актуальную версию Python, если для неё доступны зависимости
- VLC Media Player (libVLC нужен для воспроизведения через `python-vlc`)

## Установка и запуск

Из Windows Terminal:

```powershell
Set-Location 'D:\YandexMusicLocal'
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\main.py
```

Если Python 3.14 не установлен, выполни `py -0p` и выбери установленную поддерживаемую версию вместо `-3.14`.

Для проверки синтаксиса:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-project.ps1
```

Для сборки папки с Windows-приложением после установки зависимостей и обычного VLC запусти `build_local_music.bat`. Для корректной работы автономной сборки BAT пытается скопировать libVLC и плагины VLC рядом с EXE.

## Где хранятся пользовательские данные

Музыкальная коллекция не копируется в репозиторий. Настройки, SQLite-индекс и кэш обложек хранятся в пользовательском каталоге Windows, обычно `%LOCALAPPDATA%\LocalMusic`. Для Git исключены музыкальные файлы, базы, кэш, виртуальные окружения и сборки.

## Ветки Git

- `main` — стабильная версия.
- `develop` — интеграционная ветка.
- `feature/*` — новые функции.
- `fix/*` — исправления ошибок и производительности.

Изменения сначала отправляются в рабочую ветку и проверяются; затем открывается Pull Request в `develop`. Не использовать `git reset --hard` для решения обычных конфликтов и не публиковать пользовательские медиафайлы.
