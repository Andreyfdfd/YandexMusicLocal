# YandexMusicLocal

Локальный музыкальный плеер для Windows. Визуальное направление вдохновлено удобством и структурой современных музыкальных сервисов, включая Яндекс Музыку, но приложение использует собственные название, графику и локальные данные. Проект не связан с Яндексом и не использует его закрытые ресурсы.

> **Важно:** `main.py` — исходный код для разработки. Обычный запуск — через `YandexMusicLocal.exe` и ярлык **Local Music** на рабочем столе. Запуск через Python нужен только для разработческих проверок.

## Возможности

- Главная страница со всеми локальными треками, по умолчанию отсортированными по накопленному времени прослушивания.
- Локальная «Моя волна»: персональная подборка с учётом истории, избранного, новизны трека и разнообразия исполнителей.
- Отдельный раздел альбомов, по умолчанию отсортированный от альбома с наибольшим числом треков к самому короткому.
- История сессий и суммарное время прослушивания по трекам, исполнителям и альбомам. Двойной щелчок по треку в истории запускает его, если файл ещё входит в текущую библиотеку.
- Запуск с выбранным первым треком на паузе — музыка не включается автоматически.
- Инкрементальная индексация: неизменившиеся файлы не перечитываются.
- Фоновое сканирование и отложенная загрузка обложек.
- Очередь, избранное, перемотка и нижняя панель управления.
- Поддержка MP3, M4A, FLAC, WAV, Ogg/Vorbis, Opus, WMA, AAC, APE, AIFF и ALAC — при условии поддержки конкретного файла установленными VLC и Mutagen.
- Настройки, база SQLite, история и кэш обложек хранятся локально в профиле Windows.

## Установка и обычный запуск

**Обычный способ установки — один файл `Setup.exe`.** Python, Git, PyInstaller и отдельная ручная сборка на компьютере пользователя не нужны.

1. Открой [последний GitHub Release](https://github.com/Andreyfdfd/YandexMusicLocal/releases/latest) и скачай `Setup.exe`.
2. Запусти `Setup.exe`. В установщике можно выбрать две папки:
   - папку, куда будет установлена программа (по умолчанию `%LOCALAPPDATA%\\Programs\\Local Music`);
   - временную папку для загрузки и распаковки установочного пакета.
3. Нажми **«Установить»**. Установщик получает пакет последней версии из GitHub Releases, проверяет SHA-256 и распаковывает приложение вместе с необходимыми файлами VLC. Если GitHub Release недоступен напрямую (например, репозиторий закрытый), используется полная копия пакета, встроенная в `Setup.exe`.
4. Установщик создаёт ярлык **Local Music** на рабочем столе и в меню «Пуск», а рядом с файлами программы кладёт `Uninstall.exe`.
5. Запусти Local Music через ярлык. При первом запуске укажи папку со своей локальной музыкой. Музыкальная коллекция остаётся на твоём диске и не копируется в папку приложения.

Вручную устанавливать Python, VLC или другие компоненты не требуется: Windows x64-приложение поставляется со своим Python runtime и совместимым аудиодвижком libVLC. Установщик не требует прав администратора, если выбранная папка доступна текущему пользователю.

### Удаление программы

В папке установки находится **`Uninstall.exe`**. Запусти его и подтверди удаление. Деинсталлятор удаляет файлы Local Music, вложенный VLC runtime, ярлыки и запись программы в Windows.

По умолчанию настройки, база SQLite, история прослушивания и кэш в `%LOCALAPPDATA%\\LocalMusic` сохраняются — их можно удалить отдельной галочкой в деинсталляторе. Папка с твоей музыкой не удаляется ни при одном варианте.

### Доступ к GitHub Releases

Сейчас репозиторий имеет приватный статус (**private**). Поэтому страница релиза и файлы в ней доступны только аккаунтам, которым предоставлен доступ к репозиторию. Чтобы друг мог скачать `Setup.exe` непосредственно с GitHub, его GitHub-аккаунт должен иметь доступ к репозиторию. Также можно передать ему сам `Setup.exe` отдельно: полный пакет приложения уже встроен в установщик, поэтому установка не потребует доступа к GitHub.

## Разработка и проверки

- Windows 10/11
- PowerShell 7
- Python 3.12 или 3.14
- VLC Media Player нужен для локального воспроизведения через `python-vlc`

Установка Python-зависимостей для разработки:

```powershell
Set-Location 'D:\YandexMusicLocal'
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для разработческого запуска из исходного кода (не обычный пользовательский способ):

```powershell
.\.venv\Scripts\python.exe .\main.py
```

Проверка синтаксиса и регрессионные тесты:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-project.ps1
```

Безопасное обновление исходников из GitHub (скрипт остановится, если есть незакоммиченные изменения):

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-local.ps1
```

## Где хранятся пользовательские данные

Музыкальная коллекция не копируется в репозиторий. Настройки, SQLite-индекс и кэш обложек хранятся в пользовательском каталоге Windows, обычно `%LOCALAPPDATA%\LocalMusic`. Для Git исключены музыкальные файлы, базы, кэш, виртуальные окружения и сборки.

## Ветки Git

- `main` — стабильная версия.
- `develop` — интеграционная ветка.
- `feature/*` — новые функции.
- `fix/*` — исправления ошибок и производительности.

Изменения сначала отправляются в рабочую ветку и проверяются; затем открывается Pull Request в `develop`. Не использовать `git reset --hard` для решения обычных конфликтов и не публиковать пользовательские медиафайлы.
