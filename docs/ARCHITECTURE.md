# Архитектура: целевое устройство

Документ фиксирует целевое направление рефакторинга. Он не утверждает, что все перечисленные компоненты уже реализованы.

## 1. Приложение и настройки

- UI создаётся в главном потоке Qt.
- Долгие операции выполняются в фоновых задачах и передают прогресс через Qt-сигналы.
- Путь к музыкальной папке, громкость и состояние интерфейса хранятся в пользовательском каталоге Windows, а не в репозитории.
- Отсутствующий или перемещённый музыкальный каталог не должен блокировать запуск.

## 2. Индекс медиатеки

SQLite хранит индекс обнаруженных аудиофайлов и основные метаданные. Минимальный fingerprint файла: нормализованный путь, размер и время последнего изменения.

Планируемый алгоритм запуска:
1. Открыть существующий индекс и сразу показать доступные треки.
2. Выполнить сканирование выбранной папки в фоновой задаче.
3. Перечитывать теги только для новых файлов и файлов с изменившимся fingerprint.
4. Удалять из индекса записи, файлы которых больше не существуют.
5. Сохранять изменения пакетными транзакциями.

Нельзя сбрасывать базу на каждом запуске. Полное пересканирование должно быть отдельной командой пользователя.

## 3. Обложки

- Не извлекать изображения из всех аудиофайлов синхронно при запуске.
- Загружать обложку только когда она нужна видимому элементу интерфейса.
- Использовать кэш по пути файла и fingerprint/размеру файла.
- Кэшировать уменьшенные варианты и ограничивать память.
- Не читать один и тот же cover-ресурс повторно для каждой карточки/размера.
- Повреждённая или отсутствующая обложка должна приводить к нейтральной заглушке, а не к падению приложения.

## 4. Интерфейс

Сохраняем тёмную тему с жёлтым акцентом и идею локальной музыкальной библиотеки. Улучшаем типографику, выравнивание, отступы, состояния наведения, масштабирование окна и поведение длинных названий. Не копируем логотипы или закрытые графические ресурсы сторонних сервисов.

## 5. Проверка качества

Перед объединением:
- `python -m py_compile interface_argon_optimized.py`
- тест открытия приложения на Windows;
- тест пустой, недоступной и большой музыкальной папки;
- проверка, что второй запуск не перечитывает всю коллекцию без причины;
- проверка, что локальная база и музыка не попадают в Git.
