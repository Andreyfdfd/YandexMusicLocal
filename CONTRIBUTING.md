# Участие в разработке

## Ветки

- `main` — стабильные версии.
- `develop` — объединение завершённых изменений.
- `feature/<short-name>` — функциональность.
- `fix/<short-name>` — исправления.

## Рабочий цикл

1. Обновить `develop`.
2. Создать ветку `feature/*` или `fix/*`.
3. Внести небольшое связанное изменение.
4. Проверить синтаксис и запуск на Windows.
5. Сделать commit с понятным сообщением.
6. Открыть Pull Request в `develop`.

## Не коммитить

Музыку, локальные базы/кэш, пароли/токены, виртуальное окружение, `build/`, `dist/` и готовые бинарники. Перед `git add` проверять `git status --short`.
